# Epitaph

Асинхронный консольный OSINT-сканер для поиска профилей по никнейму на десятках веб-платформ. Интерфейс построен на базе фреймворка Textual в палитре Crimson Noir, сетевой стек работает на HTTPX и Playwright, а ядро изолировано от UI через асинхронную шину событий.

## Ключевые возможности

- Терминальный интерфейс (TUI) с блочной версткой, адаптивной 3-колоночной сеткой на 30 функциональных слотов и нижней командной строкой.
- Реактивное обновление: сетевые воркеры сбрасывают события в очередь, а интерфейс отрисовывает результаты без микрофризов и блокировки ввода.
- Гибридный сбор данных: быстрые асинхронные HTTP/2 запросы для простых API и headless-браузер Chromium для страниц с динамическим JS или антибот-защитой.
- Отказоустойчивость: пул прокси с поддержкой HTTP, HTTPS и SOCKS5, ротация Round-Robin и автоматический вывод нестабильных узлов в карантин через Circuit Breaker.
- Экспорт отчетов: структурированный JSON, CSV, автономный HTML на Jinja2 и печатный PDF.

## Установка и запуск в Termux (Android)

Epitaph оптимизирован для работы в мобильном окружении Termux. Во избежание конфликтов пакетной базы Termux все зависимости устанавливаются в изолированное виртуальное окружение.

### Шаг 1. Системные пакеты и сборочные инструменты

Для компиляции C/Rust расширений (включая pydantic-core, cryptography и reportlab) требуются компилятор и заголовочные файлы:

```bash
pkg update -y && pkg upgrade -y
pkg install -y python git clang build-essential binutils libxml2 libxslt libjpeg-turbo freetype rust
```

### Шаг 2. Клонирование репозитория

Файловая система чувствительна к регистру: каталог проекта именуется `Epitaph`:

```bash
git clone https://github.com/HaekNok/Epitaph.git
cd Epitaph
```

### Шаг 3. Виртуальное окружение

Создайте и активируйте виртуальное окружение (не обновляйте системный pip через команду pip install в глобальной среде Termux):

```bash
python -m venv .venv
source .venv/bin/activate
```

### Шаг 4. Установка пакета

```bash
pip install -e .
```

*Примечание по Termux:* Если Playwright не поддерживается архитектурой процессора устройства, движок автоматически работает в HTTP-режиме для всех совместимых чекеров.

### Шаг 5. Запуск приложения

Запуск возможен двумя способами:

```bash
# Способ 1: Прямая консольная команда
epitaph

# Способ 2: Запуск через модуль интерпретатора (строго в нижнем регистре)
python -m epitaph
```

### Шаг 6. Исполнение скриптов публикации коммитов

Если вы загружаете скрипты автоматизации с Google Диска в системный каталог загрузок Android, выполните:

```bash
storage/downloads && python [имя_скрипта.py]
```
*(или `cd storage/downloads && python [имя_скрипта.py]`)*

## Установка на десктопном Linux / macOS / Windows

```bash
# Клонирование
git clone https://github.com/HaekNok/Epitaph.git
cd Epitaph

# Виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate

# Установка пакета и браузера
pip install -e ".[dev]"
playwright install chromium

# Запуск
epitaph
```

## Управление в TUI

- `q` или `Ctrl+C`: немедленный выход из программы.
- `Tab` / `Shift+Tab`: переход фокуса между слотами меню, кнопкой выхода и командной строкой.
- `Клик мыши` или `Enter` на слоте: выбор соответствующего модуля.
- `Командная строка (Select function number >)`:
  - Введите число от `1` до `30` и нажмите `Enter` для активации слота.
  - Введите `q`, `quit`, `exit` или `выход` для закрытия приложения.

## Структура проекта

```text
epitaph/
├── pyproject.toml    # Конфигурация сборки Hatchling, метаданные и консольная точка входа
├── README.md         # Инструкция по сборке, развертыванию и архитектуре
├── epitaph/
│   ├── __init__.py   # Определение версии пакета
│   ├── main.py       # Основная функция запуска EpitaphApp().run()
│   ├── __main__.py   # Точка входа для вызова python -m epitaph
│   ├── core/         # Движок, планировщик задач, рейт-лимитер и шина событий
│   ├── execution/    # Базовый интерфейс чекеров и модули платформенной детекции
│   ├── models/       # Pydantic-схемы целей, результатов и статусов сканирования
│   ├── network/      # Клиенты HTTPX, менеджер прокси и Circuit Breaker
│   ├── reporting/    # Модули экспорта (JSON, CSV, HTML, PDF) и Jinja2-шаблоны
│   ├── ui/           # Приложение Textual, стили styles.tcss, экраны и виджеты
│   └── utils/        # Менеджер ротации User-Agent и форматированное логирование
└── tests/            # Наборы модульных и интеграционных тестов
```
