# Epitaph

Асинхронный сканер для поиска профилей по никнейму на различных сайтах. Интерфейс крутится в терминале через Textual, запросы гоняются через httpx и Playwright, а готовые результаты падают в отчеты нужного формата.

## Как устроена система

Архитектурно код поделен на пять слоев:

* **Интерфейс (`epitaph.ui`)**. Полностью отвязан от сети и файловой системы. Работает на Textual: забирает готовые события из очереди `asyncio.Queue` и реактивно перерисовывает таблицу и шкалу прогресса. За счет этого консоль не виснет даже при сотне параллельных запросов.
* **Оркестрация (`epitaph.core`)**. Движок `ScanEngine` координирует сканирование, `TaskScheduler` раскидывает чекеры по воркерам внутри `asyncio.TaskGroup`, а `DomainRateLimiter` следит за паузами между дерганиями одного и того же хоста.
* **Исполнители (`epitaph.execution`)**. Чекеры разбиты на два типа. Легковесные сервисы проверяются обычным HTTP-клиентом с поддержкой HTTP/2. Если на сайте висит защита Cloudflare или профиль собирается скриптами в браузере, подключается headless Chromium через Playwright.
* **Сеть и прокси (`epitaph.network`)**. Пул прокси с поддержкой HTTP, HTTPS и SOCKS5. Ротация идет по Round-Robin с оглядкой на задержку. Если нода трижды подряд выдает ошибку или ловит 429/403, срабатывает Circuit Breaker и отправляет ее остывать на 5 минут.
* **Отчеты (`epitaph.reporting`)**. Итоговые данные упаковываются в Pydantic-модели и сохраняются сразу в четырех видах: JSON, структурированный TXT, HTML на Jinja2 и PDF через ReportLab. Тяжелый рендеринг уходит в отдельный поток через `asyncio.to_thread`.

## Запуск

Для работы нужен Python 3.11+.

```bash
# Установка пакета в режиме разработки
pip install -e .

# Загрузка браузера для тяжелых чекеров
playwright install chromium

# Запуск сканера
python -m epitaph
```

Подробное описание контрактов чекеров и внутреннего взаимодействия модулей вынесено в [ARCHITECTURE.md](ARCHITECTURE.md).
